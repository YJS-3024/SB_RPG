## Input System

Unity Input System을 사용하되, Player FSM이 직접 입력 장치를 알지 않게 한다.

구조:

```text
Keyboard / Mouse
Gamepad
Mobile Touch
        ↓
Unity Input System
        ↓
Input Abstraction Layer
        ↓
Player FSM / UI / Dialogue
```

주요 구성:

- InputActions.inputactions
- InputManager
- InputContext
- PlayerInputReader
- UIInputReader
- InputRebindManager
- InputDeviceDetector
- MobileInputAdapter

Action Map:

- Gameplay
- UI
- Dialogue
- Menu
- Cutscene

키 변경은 Binding Override 기반으로 구현하고, 저장은 JSON 또는 프로젝트 저장 시스템에 연결한다.

## Local Mock Packet System

실제 서버 통신은 하지 않지만 내부 구조는 서버와 패킷을 주고받는 것처럼 설계한다.

```text
Client
↓ Request Packet
Local Mock Server
↓ Response Packet
Client
```

사용 대상:

- Login
- Patch
- Character Load
- Save
- Inventory
- Quest
- Reward
- Shop

구조:

- Packet
- Request
- Response
- PacketRouter
- PacketHandler
- LocalMockServer
- LocalRepository
- NetworkManager
