# 맵 및 월드 설계

## 맵 크기

테스트 맵은 16x16으로 시작하지만, 실제 목표는 최대 1024x1024까지 고려한다.

```text
1024 x 1024 = 1,048,576 tiles
```

따라서 타일 1개를 GameObject 1개로 배치하는 방식은 사용할 수 없다.

## 기본 방향

```text
MapData
↓
Chunk
↓
Mesh Combine / GPU Instancing
↓
Visible Chunk Streaming
```

추천 청크 구조:

```text
World 1024x1024
├─ Chunk 32x32
│  ├─ Tile Data
│  ├─ Combined Mesh
│  ├─ Collision Mesh
│  └─ Object Spawn Data
└─ ...
```

플레이어 주변 3x3 또는 5x5 청크만 활성화한다.

## 필수 최적화

- Chunk Streaming
- Mesh Combine
- Object Pooling
- Collision 단순화
- Distance Culling
- GPU Instancing
- LOD
- Addressables
- 분할 NavMesh

## 맵 생성기

수동 배치형 맵 에디터보다 자동 초안 생성 후 리터칭하는 방식을 우선한다.

```text
Map Auto Generator
↓
Scene Bake
↓
Manual Retouch Tool
↓
Map Scene 저장
↓
Purpose Scene과 연결
```

1차 기능:

- Seed 기반 생성
- 16x16, 32x32, 64x64 생성
- Biome 선택
- 타일 자동 배치
- 오브젝트 자동 배치
- Scene Bake
- 수동 Brush 리터칭
- 저장/불러오기

## 미니맵

대규모 맵에서는 미니맵을 카메라로만 처리하면 부담이 크다.

장기 방향:

```text
MapData 기반 Texture 생성
+
플레이어/NPC/퀘스트 아이콘 UI 표시
```

MiniMap과 WorldMap은 같은 MapData를 사용한다.
