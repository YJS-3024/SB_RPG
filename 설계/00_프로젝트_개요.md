# 프로젝트 개요

## 기본 방향

- 장르: 부분적 오픈월드, 샌드박스 RPG, 액션 RPG
- 엔진: Unity 6
- 그래픽: SD 캐릭터, 3D Cube Tile, Stylized Toon
- 핵심 경험: 탐험, 액션 전투, 성장, 생활 콘텐츠, 제작, 장비 수집
- 개발 형태: 1인 개발 중심, 포트폴리오 및 재사용 가능한 프레임워크 지향

## 게임의 핵심 정체성

이 프로젝트는 단순한 액션 RPG보다, 여러 시스템을 직접 설계하고 검증하는 장기 프로젝트에 가깝다.

중요한 축은 다음과 같다.

- 하데스 스타일의 빠른 액션 전투
- 무기별로 완전히 다른 플레이 감각
- 큐브 타일 기반의 대규모 월드
- 자동 생성 후 수동 리터칭 가능한 맵 제작 흐름
- SD 캐릭터와 판타지 UI가 어울리는 스타일
- AI와 문서 기반으로 함께 개발 가능한 프로젝트 구조

## 현재까지 확정된 큰 방향

- 플레이어는 FSM 기반으로 설계한다.
- 몬스터는 Behavior Tree 기반으로 설계한다.
- 캐릭터는 Skeleton, Parts, Costume, Weapon, Animator를 조립하는 구조를 사용한다.
- 입력은 Unity Input System 위에 추상화 계층을 둔다.
- 맵은 타일 GameObject 대량 배치 방식이 아니라 Chunk, MapData, Mesh Combine 또는 Instancing 중심으로 설계한다.
- 큰 구조는 AI가 완성 코드를 대신 짜기보다, 사용자가 직접 설계하고 AI가 리뷰하는 방식으로 진행한다.
