# 로드맵

## 1차 목표

목표는 모든 시스템 완성이 아니라, 핵심 루프가 동작하는 프로토타입이다.

포함 범위:

- Input Abstraction
- Character Runtime Root
- Skeleton + Costume + Weapon Attach
- Animator 연결
- Player FSM
- 이동, 대쉬, 기본 공격
- 무기 1종 전투
- 몬스터 1종 AI
- 테스트 아레나

## 2차 목표

- 무기 2~3종 추가
- 기본 Skill System
- Hit Detection
- Animation Event 연결
- Monster Behavior Tree 기본형
- Save/Load 기본형
- Scene Load Flow

## 3차 목표

- MapData 기반 맵 생성
- 16x16, 32x32 테스트맵 생성
- Chunk 구조 실험
- MiniMap 기본 표시
- Object Spawn Data
- 자동 생성 후 수동 리터칭 흐름 검증

## 4차 목표

- 생활 콘텐츠 최소 구현
- 채집, 채광, 벌목 중 1~2종
- 제작 시스템 기본형
- NPC와 상점
- 퀘스트 기본형

## 장기 목표

- 1024x1024 월드 대응 구조
- Chunk Streaming
- Mesh Combine 또는 GPU Instancing
- 무기 7종 전투 철학 완성
- UI 아이콘 체계 확장
- Local Mock Packet System
- 포트폴리오용 문서와 데모 씬 완성
