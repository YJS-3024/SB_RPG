# UI 및 아트 방향

## 전체 아트 방향

- SD 캐릭터
- Unity-Chan 계열 SD 감성
- Stylized Toon Rendering
- 3D Cube Tile 월드
- 판타지 RPG UI

## UI 아이콘 스타일

기본 규칙:

- 크기: 64x64
- 금색 프레임
- 어두운 배경
- 판타지 스타일
- 높은 가독성
- 강한 실루엣
- 중앙에 명확한 주제 배치

## 스킬 아이콘 스타일

스킬 아이콘도 UI 아이콘과 같은 64x64 기준을 사용한다.

규칙:

- Gold Frame
- Black 또는 Dark Background
- Stylized Effect
- 무기별 대표 색상
- 작은 크기에서도 읽히는 형태

## 무기별 색상

| 무기 | 대표 색상 |
|---|---|
| 검&방패 | Gold |
| 대검 | Red |
| 쌍검 | Green |
| 활 | Blue |
| 샷건 | Orange |
| 마법 | Purple |
| 주먹 | Amber |

## 필요한 아이콘 카테고리

- 메인 UI
- 전투 상태
- 무기
- 장비
- 생활 콘텐츠
- 제작
- 월드
- NPC
- 맵 아이콘
- 재화
- UI 기능
- 알림 및 상태 표시

전체적으로 250~350개 수준까지 확장될 수 있으나, 프로토타입에서는 핵심 UI와 전투/맵 아이콘만 우선한다.

## 이미지 생성 운영

이미지 생성이 필요한 경우, 일반 설계 대화와 섞지 않고 프로젝트의 이미지 전용 채팅방에서 생성하는 것을 기본 운영 방식으로 한다.
